# Quantum Machine Learning

Curso de IBM en el que se da una introducción a cómo se puede aplicar la computación cuántica al machine learning. Completé este curso a finales de agosto de 2026, y consta de una certificación por parte de Credly a la que se puede acceder desde este enlace
[Quantum Machine Learning](https://www.credly.com/badges/09fe0c1a-d636-4a62-99fd-66141be4c88b/public_url).

Los cuadernos que aparecen en esta carpeta contienen los contenidos de cada módulo del curso.

---

## 1.- Quantum Machine Learning first code

Una primera toma de contacto donde se calcula el valor de una función kernel para dos elementos de un DataSet mediante Qiskit a modo de introducción.

---

## 2.- Data encoding

En este módulo se presentan las formas de preparar los datos clásicos de un DataSet como estados cuánticos de distintas maneras. Se explican métodos desde el Amplitude encode, Phase encode hasta mapeos más complejos que vienen incluidos en librerías de Qiskit, como EfficientSU2, entre otros.

---

## 3.- Quantum Kernel Methods

Se introduce el concepto de métodos kernel en machine learning como forma de comparar similitud entre elementos de un mismo conjunto de datos. Además, se muestra cómo la matriz Kernel es una herramienta útil para el entrenamiento de modelos predictivos y cómo se puede implementar este tipo de herramientas y procedimientos en Qiskit.

--- 

## 4.- QVCs and QNNs

En este último módulo se indaga en los conceptos de Quantum Variational Circuits (QVCs) y redes neuronales cuánticas (QNNs). En concreto, se hace un seguimiento detallado de cómo se puede implementar mediante circuitos cuánticos variacionales modelos capaces de predecir patrones en imágenes. Se introduce la metodología modelo para abarcar estos problemas mediante Qiskit, desde la preparación de datos, la definición de Antsazs con las características más importantes que deben cumplir, la optimización de parámetros, así como el entrenamiento y prueba de modelos haciendo uso de librerias de machine learning clásico.
